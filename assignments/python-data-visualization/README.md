# 📘 Assignment: Python Data Visualization

## 🎯 Objective

Students will learn how to create visualizations in Python using libraries such as matplotlib or plotly. They will load a dataset and generate charts to communicate trends and insights.

## 📝 Tasks

### 🛠️ Task 1: Load and explore data

#### Description
Use pandas to read the provided `dataset.csv` file. Display the first few rows and compute basic statistics.

#### Requirements
Completed program should:

- Read `dataset.csv` into a DataFrame.
- Print the head of the DataFrame.
- Output summary statistics (e.g., `df.describe()`).


### 🛠️ Task 2: Create a chart

#### Description
Choose an appropriate chart type (line, bar, scatter, etc.) and plot data columns from the dataset using matplotlib or plotly.

#### Requirements
Completed program should:

- Import and use either `matplotlib.pyplot` or `plotly.express`.
- Produce at least one chart based on the dataset.
- Label axes and provide a title.
- Show or save the figure (e.g., `plt.show()` or `fig.show()`).


### 🛠️ Task 3: Customize visualization (optional bonus)

#### Description
Modify the chart appearance with colors, legends, or multiple series.

#### Requirements
Completed program may:

- Add colors, gridlines, or annotations.
- Combine two different chart types.
