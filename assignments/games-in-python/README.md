
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Students will build a Python implementation of the classic Hangman word-guessing game. This assignment reinforces string manipulation, loops, conditionals, and handling user input in a fun, interactive program.

## 📝 Tasks

### 🛠️ Create the Hangman Game

#### Description
Write a Python program that plays the Hangman game. The program should randomly choose a word from a list, prompt the player for letter guesses, and update the display showing progress. The game continues until the word is guessed or the player runs out of attempts.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept single-letter guesses and show current progress (e.g. `_ _ a _ _` format)
- Track incorrect guesses and display remaining attempts
- End with a clear win or lose message depending on whether the word is revealed before attempts expire


### 🛠️ Add Optional Enhancements

#### Description
Extend your basic Hangman game with additional features that improve playability or user experience. These enhancements are not required but will deepen your understanding of program logic.

#### Requirements
Enhanced program should include at least one of the following:

- Allow players to guess the entire word at once
- Prevent repeated guesses by tracking letters already tried
- Display a simple ASCII-art hangman figure that progresses with each wrong guess (optional visual feedback)
